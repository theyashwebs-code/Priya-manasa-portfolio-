# Priya Manasa Portfolio — HTML, CSS & JavaScript

This is a standalone static conversion of the supplied portfolio design. It does not require React, npm, or a build step.

## Run locally
Open `index.html` in a browser, or open this folder in VS Code and use Live Server.

## Files
- `index.html` — portfolio markup
- `style.css` — styling and responsive rules
- `main.js` — project case-study dialog, mobile menu, copy-email action and back-to-top
- `priya-portrait.webp` — hero portrait

The Awards & Recognition category labels use non-wrapping pills on desktop and a dedicated row on narrow mobile screens to prevent awkward line breaks. The contact section uses the Email Priya / LinkedIn profile / Copy Email arrangement requested from the reference ZIP.
